# 安全与授权边界

不得提交真实 Token、Cookie、私有目录清单或带凭据 URL。普通日志与性能诊断只输出计数和固定错误，不输出服务原文。

## 存储与同步

默认只保留会话。明确选择同步后，凭据在 Vault 内为**明文 JSON**。0700/0600 不是加密，不保证 Windows ACL，不能抵御其他同权限软件、恶意插件或整库泄露。`.gitignore` 也不是保密边界。

以临时文件、fsync、rename 成对替换两个 Token，禁止账号文件及 Vault 下插件路径经过符号链接。根目录可解析系统级别规范路径。读取限 32 KiB，标准账号最多 32 个，目录项最多 256 个；冲突副本不自动采用，单个坏文件不会隐藏其他健康账号。取消写入在提交前检查，不删除旧文件来掩盖失败。

仅保证单机流程与有限的版本冲突检查，不能宣称坚果云提供原子同步或分布式锁。每次真实使用重新读取本机文件；无 fs.watch 或周期刷新。Token 请求在 TLS 建立后、发送前保存 pending。只有明确未发送的失败可以回退自己的标记；响应丢失、进程退出、保存失败等保留标记，不重放可能消费的旧 Token。同步新凭据后可再尝试，否则重新授权。

## OAuth

OpenList 收到授权码和续期凭据，应用身份及平台权限属于它。没有打包应用 Secret，不能声称本插件已独立获批。个人使用不自动解决服务条款或未来公开分发权限。

隔离窗口使用唯一非持久 partition，sandbox/contextIsolation 开启，Node、webview、开发工具关闭，无 preload、页面脚本注入或任意 IPC。拒绝权限、下载和新窗口。主导航只允许指定百度登录域名；随机 256 位 state 必须在回调中唯一匹配。授权码在发给 broker 前被截获，随后由固定 HTTPS 请求交换，仅读取 302 的 Location 信封而不跟随。含 Token 的结果页不在窗口打开。

窗口能力依赖 Obsidian 宿主，实际加载兼容性仍需验证。没有能力时明确报错并提供手动入口，不安装远程桥接模块。手动 Token 入口是用户主动输入，必须核验账号后再确认保存。

## 网络与扩展

仅白名单 HTTPS 端点；普通请求禁止跟随重定向，OAuth 信封只接收固定 broker 根路径。20 秒网络阶段截止、2 MiB 响应、3 个并发、64 个排队；授权失效最多重试一次，HTTP 限流使用每来源的有界冷却，不无限重试。

网盘权限不一定是只读，但本版没有远端写入或下载接口。引用不包含 Token；渲染使用 textContent。外部打开器由可信插件注册，不传递凭据；其内部权限仍属于 Obsidian 插件信任模型，不能将接口隔离宣传为沙箱。

网页定位依赖浏览器账号，可能与插件账号不同，必须提示核对。未实现本地附件自动下载或缓存；无后台监听服务。
